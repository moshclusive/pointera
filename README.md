# Pointera - Mouse Effects for Presentations & Screen Recording

<p align="center"><img src="pointera.png" alt="pointera logo" width="128"></p>

> A Windows desktop tool that adds presentation-style mouse effects - a smooth cursor trail, click ripples, a spotlight, and an on-screen keystroke display - so viewers can follow exactly what you are doing.

## Features

- **Cursor trail** - A smooth fading line follows the mouse (configurable lifetime, length, thickness, color, and opacity).
- **Click highlight** - A ripple ring appears on every mouse click.
- **Spotlight mode** - Dims the whole screen except a circle around the cursor. Toggle with `Ctrl+Shift+S`.
- **Keystroke OSD** - Shows pressed keys and mouse buttons on screen, so viewers can see what the presenter types and clicks.
- **Settings window & system tray** - Tabbed settings for the trail, spotlight, on-screen display, colors, and hotkeys, with a custom hotkey capture widget. Settings are saved to `pointera_config.json` next to the app.
- **Fully offline** - No network, no account, no sync. Everything runs locally.

## Download & Install

1. Go to the [Releases](../../releases) page.
2. Download `Pointera.exe` (portable, single file - no install needed).
3. Double-click it to run. It lives in the system tray; right-click the tray icon for settings.

## How to Use

1. Start Pointera - it sits in the system tray.
2. Move the mouse: the trail follows. Click: a ripple appears.
3. Press `Ctrl+Shift+S` to turn the spotlight on or off.
4. Open Settings from the tray icon to change trail length, colors, spotlight size, the on-screen display, and hotkeys.
